# v0.7 Frozen Case Matrix

Status: **frozen before learner implementation**

All episodes retain the v0.6 raw schema. Error magnitude is fixed at `0.60` and is non-identifying.

## Current-language signatures

Four training signatures are used:

- `S_A`: current-language adequate `composition_probe`;
- `S_R`: current-language adequate `reference_probe`;
- `S_D`: collision between `direction_forward_probe` and `direction_reverse_probe`;
- `S_C`: collision between `center_heavy_probe` and `edge_heavy_probe`.

A fifth held-out signature `S_U` is unsupported and must remain `unknown`.

The hostile labels within `S_D` and within `S_C` have identical paired measurements and identical surface hints; they differ only in raw ordered traces.

## Frozen scalar fields

Training predictions descend by `0.02` from `0.90`; each outcome is `prediction - 0.60`.

Held-out predictions descend by `0.03` from `0.58`; each outcome is `prediction - 0.60`.

These values are intentionally irrelevant to the target distinctions.

## Expected boundary behavior

```text
S_A -> adequate
S_R -> adequate
S_D -> inadequate
S_C -> inadequate
S_U -> unknown
```

The boundary-gated synthesizer may invoke expression construction only for `S_D` and `S_C`.
