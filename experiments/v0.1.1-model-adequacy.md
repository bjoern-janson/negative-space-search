# Experiment v0.1.1 — More Data or a Better Question?

Status: **pre-registered before execution**.

## Research question

Does explicit causal negative-space search select a model-adequacy test after repeated ordinary causal probes fail, where a strong general causal reasoner continues searching within the current model?

## Systems compared

Primary comparison:

```text
causal_negative_space_search
general_causal_reasoner
```

Other existing baselines remain in the runner as diagnostic controls.

All policies receive the same initial observation and evidence affordances.

## Environment

Use `model_adequacy_pair()` from `simulator.py`.

The pair contains:

```text
World A: within-model uncertainty
World B: model inadequacy
```

Initial observations are exactly equal.

Available evidence in both worlds:

```text
ordinary_discriminator
model_disrupting_probe
```

## Pre-run predictions

### Causal Negative-Space Search

Expected initial behavior:

```text
action = investigate
requested_evidence = model_disrupting_probe
```

Expected after the supplied model-disrupting result:

```text
World A -> within_model_uncertainty + investigate
World B -> model_inadequacy_suspected + abstain
```

### Strong general causal reasoner

Expected initial behavior:

```text
action = investigate
requested_evidence = ordinary_discriminator
```

Expected interpretation if the model-disrupting probe is supplied anyway:

```text
World A -> within_model_uncertainty + investigate
World B -> model_inadequacy_suspected + abstain
```

Thus the predicted difference is **evidence acquisition**, not post-evidence causal interpretation.

## Falsification / constraint conditions

The proposed `Psi_NS` advantage is not supported if any of the following occur:

- `causal_negative_space_search` does not select `model_disrupting_probe`;
- the strong causal reasoner also selects `model_disrupting_probe` under matched information;
- the pair is not actually observationally equivalent before evidence acquisition;
- ordinary evidence itself discriminates the two worlds;
- `Psi_NS` cannot correctly separate the two regimes after the probe.

Even a positive result constrains authority to this toy evidence-selection mechanism. It does not establish general superiority over causal reasoning.

## Preserved prior constraint

NR-002 remains active: v0.1 showed no incremental advantage over strong general causal reasoning on ordinary observational equivalence. v0.1.1 tests a narrower hypothesized difference rather than rewriting that result.
