## Primary result

| Policy | True escalation | False escalation | Correct evidence selection | Held-out correct selection | Post-evidence interpretation | Evidence cost |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| frozen general causal reasoner | 0.00 | 0.00 | 0.50 | 0.50 | 1.00 | 0.80 |
| frozen causal negative-space search | 1.00 | 1.00 | 0.50 | 0.50 | 1.00 | 3.20 |

The frozen v0.1.1 policies expose the expected opposite failure modes:

```text
causal_negative_space_search -> escalate whenever ordinary hypotheses remain unresolved
                              -> true escalation 1.0, false escalation 1.0

general_causal_reasoner      -> stay within the current model
                              -> true escalation 0.0, false escalation 0.0
```

Both history-aware policies used failure structure rather than failure count and achieved selective escalation on the frozen development and held-out surface cases.

## Held-out control

The held-out `held_U_1` case contained same-sign residuals across all prior failures but weak magnitude relative to measurement noise. Both history-aware policies correctly continued within-model investigation rather than escalating.

This rules out a simple:

```text
same sign -> model failure
```

shortcut on the current matrix.

## Incremental-value result

The primary preregistered null was not rejected:

```text
history_aware_negative_space_search
<= history_aware_general_causal_reasoner
```

The two history-aware policies were identical on every reported metric.

Therefore v0.2 supports:

> Structured failure history can improve selective evidence acquisition by distinguishing model-inadequacy signatures from ordinary uncertainty.

It does **not** support:

> Explicit negative-space framing adds value beyond a strong history-aware causal reasoner given the same failure summary and escalation rule.

This is the central v0.2 boundary.

## Search vs interpretation

All four primary policies scored `1.00` on post-evidence regime interpretation when the model-disrupting result was supplied.

The empirical difference remains localized to:

```text
evidence selection / search control
```

rather than:

```text
causal interpretation after evidence arrives.
```

## Relationship to v0.1.1

v0.1.1 showed that an explicit negative-space policy could select a model-disrupting probe where the frozen general causal baseline stayed inside the model.

v0.2 shows that this advantage disappears when the strong causal baseline is given the same history-sensitive escalation competence.

The defensible update is therefore narrower:

> The useful capability identified so far is history-sensitive selective escalation, not a demonstrated uniquely negative-space reasoning mechanism.

## Limitations

- The held-out split is a frozen surface-form split, not a blind external benchmark.
- Both history-aware policies share the same standardized-residual summary and threshold.
- The synthetic residual structures are deliberately separable.
- The benchmark does not yet test learning the escalation rule from prior outcomes.
- It does not test novel failure structures outside the residual-persistence representation.
- It does not test whether `H` itself improves through accumulated diagnostic failures.

## Next discriminator

Do not make the history-aware negative-space policy more elaborate merely to beat the matched causal baseline.

The next useful experiment should test **search-process learning** rather than framing:

1. expose both strong policies to training histories with several failure structures;
2. withhold a structurally different escalation pattern;
3. allow policy/search parameters to update from prior diagnostic outcomes;
4. evaluate whether either process transfers the learned evidence-allocation rule to the novel failure structure;
5. preserve a no-incremental-value result if ordinary causal search learns equally well.

The question is now:

> Can the search process improve from attributed discovery failures, and does explicit negative-space structure contribute anything beyond strong adaptive causal search?
