# v0.6 Frozen Case Matrix

Committed before v0.6 learner implementation.

The frozen current language is the v0.5 language. Its primitive thresholds are:

```text
close: abs(left - right) <= 0.08
far: abs(left - right) >= 0.65
sign_disagree: left * right < 0 and min(abs(left), abs(right)) >= 0.10
hint_high: surface_hint >= 0.60
hint_low: surface_hint <= -0.60
hint_near_zero: abs(surface_hint) <= 0.15
```

All pairwise `AND` compositions of those primitive predicates are also in the current language.

The current language does **not** inspect `ordered_trace`.

All prediction errors are `0.60`, so error magnitude is non-identifying.

## Hostile equivalence condition

The benchmark must verify programmatically that:

```text
phi_L(T_UP1)   = phi_L(T_DOWN1)
phi_L(T_UP2)   = phi_L(T_DOWN2)
phi_L(H_ORDER_UP) = phi_L(H_ORDER_DOWN)
```

and that the held-out order signature belongs to a resolved equivalence class containing both:

```text
order_up_probe
order_down_probe
```

The raw traces are not identical and a withheld oracle relation can distinguish them.

## Oracle-only relations

Frozen before execution:

```text
trace_increasing := x0 < x1 < x2
trace_decreasing := x0 > x1 > x2
```

These are unavailable to all primary systems. They are provided only to the expanded-language oracle as a recoverability control.
