# v0.3 Preregistration — Representation-Dependent Transfer

Status: **preregistered before policy implementation**

## Question

Does a negative-space-oriented failure representation improve transfer to novel adaptive failure topologies beyond a generic adaptive causal history representation, under matched raw observations, reasoning budget, action space, and experiment budget?

The benchmark is not designed to show that negative-space reasoning is generally superior. It tests whether preserving additional structure about *why a possibility was absent or a correction failed* changes later evidence allocation on held-out cases.

## Frozen comparison

Both systems observe the same raw training episodes.

### Generic history representation

Retains only:

```text
prediction
outcome
error magnitude
selected experiment
```

### Structured negative-space history representation

Retains the same fields plus typed relations already present in the raw episode:

```text
assumed absence / excluded possibility
causal diagnosis at time of action
intervention attempted
challenge-channel identity / dependency relation
payoff regime identifier
coordination topology
whether the outcome was unclassified by the current causal vocabulary
```

These are representation fields, not new theory primitives.

The richer representation receives no extra raw observations. It preserves distinctions that the generic compressor discards after each training episode.

## Training failure families

Training exposes three structures with surface forms different from evaluation:

1. **shared-challenge dependence** — apparently independent confirmations share a hidden challenge channel;
2. **payoff-regime drift** — a formerly valid strategy fails because the external payoff regime changes;
3. **coordination-topology mismatch** — a successful pairwise coordination intervention fails when applied to a different topology.

Each training episode includes the eventual diagnostic outcome so both learners can update from attributed failure.

## Held-out cases

Four held-out cases are frozen before policy implementation:

| Case | Hidden structure | Correct next evidence |
| --- | --- | --- |
| `H_DEP` | consensus generated by a shared validator dependency | `independence_probe` |
| `H_PAY` | payoff function changed while model predictions remain internally coherent | `payoff_regime_probe` |
| `H_NET` | coordination mechanism changed from threshold/pairwise to network topology | `topology_probe` |
| `H_NOVEL` | current causal vocabulary cannot classify the residual | `model_disrupting_probe` |

`H_NOVEL` is intentionally outside the three training topologies. It tests whether a representation preserves enough unresolved-structure information to recommend checking model adequacy rather than forcing a known attribution.

## Matched conditions

Both systems receive:

- the same raw training episodes;
- the same held-out observations;
- the same four evidence actions;
- the same evidence costs;
- the same maximum one-probe decision budget per held-out case;
- the same deterministic nearest-structure decision rule.

They differ only in the persistent representation produced from training history.

## Primary metrics

Report separately:

```text
held_out_evidence_selection_rate
known_topology_transfer_rate
novel_topology_model_check_rate
false_model_check_rate
evidence_cost
```

No composite score.

## Primary null

```text
H0:
structured_negative_space_representation
<= generic_causal_history_representation
```

on held-out evidence selection under matched conditions.

## Interpretation constraints

A positive result would support only:

> Preserving typed relations about absence, attribution, challenge independence, payoff regime, and coordination structure can improve transfer in this synthetic benchmark relative to a compressed prediction/outcome/error history.

It would not establish:

- a unique negative-space algorithm;
- superiority over a generic causal learner allowed to preserve the same typed relations;
- real-world transfer;
- that all listed representation fields are necessary;
- that the representation should be expanded further.

If a generic learner given the same typed representation performs equally well, the result belongs to representation quality rather than negative-space identity.

## Failure-preserving rule

Do not revise the held-out cases or scoring after observing the first CI result. Any repair must be evaluated in a later version.
