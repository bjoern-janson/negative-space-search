# v0.5 Frozen Case Matrix

This matrix was committed before v0.5 learner implementation.

Relation thresholds inherit v0.4:

```text
close: abs(left - right) <= 0.08
far: abs(left - right) >= 0.65
sign_disagree: left * right < 0 and min(abs(left), abs(right)) >= 0.10
hint_high: surface_hint >= 0.60
hint_low: surface_hint <= -0.60
hint_near_zero: abs(surface_hint) <= 0.15
```

All training and held-out prediction errors are `0.60`, so error magnitude is non-identifying.

## Intended training structure

The supplied single basis contains perfect relations for the three controls:

```text
independence_probe  -> pair2_close
payoff_regime_probe -> pair2_far
topology_probe      -> pair2_sign_disagree
```

For `interaction_probe`:

```text
pair0_close is active on all T_I* and all T_D*
pair1_far   is active on all T_I* and all T_P*
```

Therefore each constituent alone has balanced accuracy below `0.90`.

The withheld conjunction:

```text
pair0_close AND pair1_far
```

is active on all and only the four `T_I*` episodes.

## Frozen adversarial checks

1. Both interaction held-outs activate the withheld conjunction.
2. `H_DEP_ONLY` activates `pair0_close` but not `pair1_far`.
3. `H_PAY_ONLY` activates `pair1_far` but not `pair0_close`.
4. `H_NOVEL` activates none of `pair2_close`, `pair2_far`, `pair2_sign_disagree`, or the withheld conjunction.
5. Surface hints are deliberately inconsistent with the probe families.
6. No held-out case is an exact numeric duplicate of a training episode.
