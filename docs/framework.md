# Framework

## Status

This document is the minimal conceptual contract for the initial benchmark. It is intentionally narrower than a general theory of adaptation.

## Constitutional invariant

> **Keep possibility open; keep authority earned.**

The project preserves a strict separation between possibility management and authority management:

```text
possibility space ≠ authority space
```

Negative-Space Search (`Ψ`) may allocate investigative attention. It does not grant epistemic authority.

Evidence enters through external consequence and is interpreted by an evidence-conditioned update process (`U`). Correctable Lineage governs what remains inherited after that update.

## Minimal cycle

```text
L_t → Ψ_t → C_t → W/e_t → U_t → L_{t+1}
```

- `L_t`: inherited validated structure.
- `Ψ_t`: embedded causal search over possible deficiencies in the current equilibrium.
- `C_t`: candidate intervention, distinction, or investigation target.
- `W/e_t`: external consequence and evidence.
- `U_t`: evidence-conditioned update.
- `L_{t+1}`: inherited structure after scoped revision.

The bridge is procedural, not a new ontology:

```text
candidate generation → external discrimination → scoped inheritance
```

## Two prohibited collapses

### Possibility collapse

Current authority is treated as the full boundary of what may be investigated.

```text
not currently validated → not worth exploring
```

Negative-Space Search is intended to resist this failure.

### Authority inflation

Possibilities, intuitions, absences, or partial evidence receive more authority than they have earned.

```text
candidate → authority
```

Correctable Lineage is intended to resist this failure.

## Absence is a causal question

The initial benchmark treats an observed absence as evidence requiring explanation, not as evidence of opportunity.

Initial causal hypotheses are:

- **underinvestment** — a represented capability is valuable but insufficiently rewarded relative to its cost;
- **underrepresentation** — the current interface cannot express or measure a consequential distinction;
- **justified selection** — the capability is absent because prior selection against it was appropriate;
- **coordination failure** — unilateral adoption is insufficient; value depends on collective adoption or shared infrastructure.

These mechanisms may coexist. They are hypotheses, not exhaustive ontology.

A **model-inadequate / novel-cause case** is not a fifth world-state category. It is evidence that the current causal vocabulary cannot adequately represent the observed ecology.

## Search output

Given observable ecology state `Z_t`, the search process should separate diagnosis, confidence, and action.

Conceptually:

```text
Ψ(Z_t) → (q, n_hat, Y_hat, d, c)
```

where:

- `q`: candidate consequential absence;
- `n_hat`: causal hypothesis or mixture;
- `Y_hat`: predicted consequence of evidence acquisition or intervention;
- `d`: decision;
- `c`: calibrated confidence / identifiability.

The initial decision space is:

```text
intervene | preserve | investigate | abstain
```

`investigate` is required when competing causal explanations are not identifiable from current evidence and a discriminating observation can be specified.

`abstain` is required when the current evidence or representation does not license a more specific decision.

## Search-process learning

Diagnostic history must preserve enough information to distinguish failures of:

- candidate selection;
- causal diagnosis;
- evidence acquisition;
- intervention matching;
- consequence prediction;
- causal vocabulary.

A failed intervention must not automatically update the whole search method. Revision should follow what the failure actually identifies.

## Anti-expansion rule

Do not add a new primitive because it is useful descriptively.

Add a primitive only when a recurring empirical failure cannot be discriminated using the current structure.

The initial benchmark, not conceptual elegance, determines whether the framework expands.
