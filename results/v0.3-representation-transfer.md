## Primary result

| Persistent history representation | Held-out evidence selection | Known-topology transfer | Novel-topology model check | False model checks | Evidence cost |
| --- | ---: | ---: | ---: | ---: | ---: |
| generic compressed causal history | 0.00 | 0.00 | 0.00 | 0.00 | 1.00 |
| typed general causal history | **1.00** | **1.00** | **1.00** | 0.00 | 1.00 |
| structured negative-space history | **1.00** | **1.00** | **1.00** | 0.00 | 1.00 |

The two typed-history policies were implemented with the same representation and decision rule and differed only in name. They produced identical decisions on all four held-out cases.

## Case-level result

The compressed learner followed misleading prediction/outcome similarity:

```text
H_DEP   -> T_NET -> topology_probe        (wrong)
H_PAY   -> T_DEP -> independence_probe    (wrong)
H_NET   -> T_PAY -> payoff_regime_probe   (wrong)
H_NOVEL -> T_PAY -> payoff_regime_probe   (wrong)
```

The typed representations preserved the relations needed for transfer:

```text
H_DEP   -> independence_probe
H_PAY   -> payoff_regime_probe
H_NET   -> topology_probe
H_NOVEL -> model_disrupting_probe
```

## Evidential update

The benchmark supports the narrow representation claim:

> When superficial error statistics are non-identifying or misleading, preserving typed relations about challenge dependence, payoff-regime change, coordination topology, and unresolved classification can improve transfer of evidence-selection decisions relative to a history compressed to prediction, outcome, error magnitude, and selected experiment.

However, the benchmark rejects a stronger identity claim:

```text
structured_negative_space_history
=
typed_general_causal_history
```

on every reported metric.

Therefore the observed gain belongs to **representation quality**, not to a demonstrated uniquely negative-space mechanism.

## What v0.3 does not establish

- that the selected typed fields are minimal or optimal;
- that a strong generic learner could not learn those fields automatically;
- that negative-space terminology contributes causal performance;
- transfer outside the hand-constructed synthetic structures;
- robustness when typed relations are noisy, partially observed, or incorrectly attributed;
- superiority over learned representation methods;
- that the novel-case model check generalizes beyond the explicit `unclassified_residual` distinction.

The case matrix deliberately permutes surface prediction/outcome statistics relative to causal topology. The result is therefore a representation ablation by construction, not evidence that generic causal learning broadly fails.

## Relationship to v0.2

v0.2 found no difference between matched history-aware negative-space and causal search when both used the same failure summary.

v0.3 is consistent with that boundary. It shows that changing what history preserves can strongly change transfer, while changing the label from typed causal to negative-space does not.

The current defensible picture is:

```text
useful capability so far:
  preserve causally relevant failure structure in H

not established:
  a unique negative-space search mechanism
```

## Next discriminator

The next useful experiment should attack the typed representation itself rather than adding more fields.

A stronger v0.3.x or v0.4 should:

1. make typed relations noisy or partially observed;
2. include irrelevant typed fields so richer representation has a cost;
3. allow a generic learner to learn its own representation from raw histories;
4. evaluate which distinctions are actually necessary for transfer;
5. include cases where the typed negative-space representation misleads;
6. preserve the null if a learned generic representation recovers the same advantage.

The next question is:

> Does explicitly preserving negative-space-relevant distinctions provide a robust representation advantage once the representation itself must be learned, selected, and paid for?
