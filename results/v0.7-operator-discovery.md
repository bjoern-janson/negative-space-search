## Frozen search substrate

The pre-repair language remained the v0.6 language:

```text
78 current-language expressions
```

The v0.7 generic synthesis meta-language contained:

```text
terminals: t0, t1, t2, t3
constructors: ADD, SUB, GT, LT
numeric expressions: 26
generated predicates: 1300
```

No numeric constants or semantic target predicates such as `trace_increasing`, `direction`, `center_heavy`, or `edge_heavy` were supplied.

The two hostile families were distinct current-language equivalence classes, and each family contained conflicting resolved labels that were identical under all 78 current-language expressions.

## Constructed abstractions

Both generic synthesis systems independently selected the same four generated predicates:

```text
direction_forward_probe -> GT(t3,t0)
direction_reverse_probe -> GT(t0,t3)
center_heavy_probe      -> GT(ADD(t1,t2),ADD(t0,t3))
edge_heavy_probe        -> GT(ADD(t0,t3),ADD(t1,t2))
```

The direction predicates had representation complexity `3`; the center/edge predicates had complexity `7`.

Each retained predicate had training balanced accuracy `1.0` inside its implicated collision class and transferred correctly to held-out traces with changed numeric values.

## Central null/localization

The v0.7 result does **not** show that boundary gating produces better abstractions.

The generated operators, held-out repair accuracy, multi-family transfer, `Q_invention`, and final representation cost were identical:

```text
invention quality: gated = always-expand
held-out repair: 1.0 = 1.0
multi-family transfer: 1.0 = 1.0
Q_invention: 1.0 = 1.0
representation cost: 20 = 20
```

The difference was entirely in **when synthesis was licensed**:

```text
boundary-gated search cost = 5200
always-expand search cost  = 7800
```

and:

```text
boundary-gated false expansion = 0.0
always-expand false expansion  = 1.0
```

Thus boundary diagnosis reduced synthesis evaluations by one third while retaining the same final abstractions and transfer performance.

## Control behavior

The current-language assimilator forced one existing label in each collision and therefore achieved only `0.50` hostile-case selection with `0.50` false assimilation. It never transferred perfectly across either hostile family.

The conservative abstainer avoided false assimilation but did not repair the language.

The boundary-only auditor correctly diagnosed both construction-language collisions but stopped at `language_expansion_probe`; it therefore demonstrates that boundary detection alone is insufficient for repair.

## Evidential update

v0.7 supports the narrow claim:

> In this controlled benchmark, after a demonstrated construction-language collision, a generic expression synthesizer can construct previously unsupplied full predicates from a supplied primitive meta-language and improve held-out discrimination. Conditioning that same synthesizer on boundary diagnosis preserves invention quality while reducing unnecessary search and avoiding expansion in already-adequate regions.

The demonstrated transition is:

```text
current-language collision
-> boundary diagnosis
-> conditional generic synthesis
-> retained candidate abstraction
-> held-out discrimination
```

The strongest supported contribution is therefore **adaptive representational economy / causal timing of expansion**, not superior invention quality.

## Authority boundary

A generated predicate is not a validated causal claim.

v0.7 only shows that the predicate is a useful candidate coordinate for discriminating the frozen synthetic histories and held-out cases. It does not grant causal authority beyond that identification footprint.

## What v0.7 does not establish

Most importantly:

```text
construction inside supplied meta-language != invention of the meta-language
```

The system was supplied with:

- the raw ordered-trace interface;
- indexed terminals `t0..t3`;
- `ADD`, `SUB`, `GT`, and `LT` constructors;
- the expression-depth limit;
- the 1300-candidate finite enumeration procedure;
- the scoring rule;
- the perfect-training-discrimination retention rule;
- the current-language collision detector.

Therefore v0.7 does not establish:

- autonomous invention of primitive operations;
- autonomous invention of the search generator `G`;
- discovery of new sensors or raw observation channels;
- open-ended scientific concept invention;
- causal truth of the synthesized expressions;
- robustness to corrupted resolving labels;
- superiority over generic program synthesis, AutoML, or learned feature systems outside this matched finite benchmark;
- superiority over language-model abstraction generation;
- unique causal value of negative-space terminology.

A genuine language-model abstraction baseline was intentionally not simulated with a hand-written proxy. Any such comparison should use a frozen real model/version and exported benchmark data in a separate reproducible run.

## Relationship to v0.6

v0.6 established:

```text
current language is demonstrably non-identifying
-> request expansion
```

v0.7 establishes one additional step:

```text
request expansion
-> construct transferable predicates inside a supplied generic meta-language
```

It does not establish the next stronger step:

```text
meta-language itself inadequate
-> invent a new generator / primitive substrate
```

## Next empirical boundary

The remaining frontier is not another semantic target class. It is whether the construction machinery itself can be challenged without quietly supplying its repair.

Useful follow-up tests include:

1. withhold a primitive constructor required for a demonstrated collision;
2. compare against a matched generic program-synthesis system with identical primitive and compute budgets;
3. run a genuine frozen language-model abstraction baseline on exported histories;
4. introduce ambiguous or corrupted resolution attribution;
5. test whether boundary gating still improves total epistemic/search cost when synthesis success is uncertain rather than guaranteed.

A null should be preserved if generic synthesis or an external abstraction learner matches the same repair at equal or lower total cost.
