# v0.1 Hostile Observational-Equivalence Experiment

Status: **pre-registered / no result recorded in this file**.

## Question

Can a search policy recognize that two causally different absences are non-identifiable from the same initial observable ecology and request evidence that discriminates them rather than guessing?

## Worlds

The simulator constructs two hidden worlds with the same initial observation:

```text
World I: underinvestment
World S: justified selection
Z_I == Z_S
```

The hidden difference is external value:

```text
World I: controlled external value > 0
World S: controlled external value < 0
```

## Discriminating evidence

```text
controlled_external_value_test
```

The evidence action is available in both worlds and reveals the sign of external value under matched conditions.

## Policies

Compare the complete v0.1 baseline set:

1. seeded random action;
2. gap heuristic;
3. novelty heuristic;
4. short-term performance heuristic;
5. self-confirming opportunity search;
6. general causal reasoner;
7. causal negative-space search.

All policies receive the identical initial `EcologyObservation` object in both worlds.

## Pass condition

A policy passes the initial hostile test only if it:

1. does not immediately intervene or preserve as though the latent cause were identified;
2. chooses `investigate` or calibrated `abstain`;
3. requests `controlled_external_value_test`;
4. produces the same initial action for the same initial observation.

A correct latent-cause guess without discriminating evidence does **not** pass.

## Expected discriminator

The gap and self-confirming opportunity baselines are expected to fail by converting low prevalence into intervention pressure.

The general causal reasoner and causal negative-space search are expected to request the controlled external-value test rather than guess.

This expectation is a prediction, not a result.

## Failure interpretation

If causal negative-space search guesses either latent cause, localize the failure to evidence/identifiability handling before revising the broader architecture.

If the general causal reasoner performs as well as causal negative-space search, that is evidence against claiming incremental value for explicit negative-space structure on this test.
