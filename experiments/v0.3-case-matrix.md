## Held-out cases

The numeric prediction/outcome patterns are deliberately permuted relative to causal structure so a learner that retained only generic error statistics cannot rely on superficial nearest-neighbor similarity.

| `H_NOVEL` | 0.62 | 0.02 | 0.60 | no | no | no | yes | `model_disrupting_probe` |

Expected compressed-history nearest matches are therefore intentionally wrong for the held-out structures:

```text
H_DEP   -> T_NET
H_PAY   -> T_DEP
H_NET   -> T_PAY
H_NOVEL -> T_PAY
```

This is not meant to show that numeric nearest-neighbor causal learning is generally weak. It isolates whether preserving typed causal relations changes transfer when surface error statistics are non-identifying or misleading.
